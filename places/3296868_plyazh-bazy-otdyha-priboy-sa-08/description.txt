Широкий песчано-галечный пляж находится на берегу Чёрного моря, в Каламитском заливе.

Вода чистая, море с песчаным дном, вход пологий, подходит для отдыха с детьми. На пляже имеется оборудованный спуск в море для лиц с ограниченными возможностями.

На пляже есть бунгало, спортивная водные аттракционы, площадка для игры в волейбол, детский сектор с аттракционами, зона отдыха для людей с ограниченными физическими возможностями. Напрокат можно взять шезлонги.

На территории установлены душевые, фонтанчики с питьевой водой, кабинки для переодевания. Пляж оборудован деревянными дорожками. Работают спасательные пункты, торговые точки.
