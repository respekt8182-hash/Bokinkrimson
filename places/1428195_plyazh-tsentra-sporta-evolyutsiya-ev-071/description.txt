Широкий песчаный пляж находится в Заозерном.

Вода чистая, море неглубокое с песчаным дном, вход пологий, поэтому пляж подходит для отдыха с детьми.

На территории установлены теневые навесы, душевые кабинки, фонтанчики с питьевой водой, кабинки для переодевания, шезлонги с зонтами, бунгало. Работает спасательный пункт, пункты проката пляжных принадлежностей. Есть площадка для игры в волейбол.

Дополнительно пляж оборудован для маломобильных граждан.
