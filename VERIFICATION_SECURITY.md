# Verification security

## Что найдено

Схема содержит `PropertyDocument`, а пользовательское соглашение описывало возможность запроса фото документов и видеоизображения лица.

## Требования к безопасной обработке

- Запрашивать только минимально необходимые документы.
- Не публиковать паспортные данные и документы.
- Хранить документы в приватном хранилище, не в публичном `/uploads`.
- Проверять MIME type и размер файла.
- Ограничивать доступ только администраторам с нужной ролью.
- Логировать доступ и действия с документами.
- Удалять документы после достижения цели, если нет законного основания хранения.
- Не использовать документы для иных целей без отдельного основания.

Если инфраструктуры приватного хранения или антивирусной проверки нет, прием чувствительных документов должен быть ограничен ручным регламентом.
