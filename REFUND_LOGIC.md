# Refund logic

Возвраты относятся только к услугам платформы: размещение карточки, продление, продвижение, фотосъемка, дополнительный автомобиль и другие отдельно описанные услуги.

Сайт не принимает оплату проживания, поэтому возвраты оплаты проживания не обрабатываются платформой.

Рекомендуемая логика:

1. Пользователь создает отдельное обращение на возврат.
2. Система связывает обращение с `PlatformServiceOrder` или `Payment`.
3. Администратор проверяет основание, сумму и исполненность услуги.
4. При одобрении создается `RefundRequest`.
5. Для НПД формируется чек возврата или задача на ручное формирование.
6. Пользователю отправляется результат обработки.

Необходимо отдельно утвердить правила невозврата/частичного возврата у юриста.

Реализовано:

- публичная форма `/refund-request`;
- API `/api/refund-requests`;
- модель `RefundRequest`;
- helper `src/lib/refunds.ts` с предварительной формулой:

```ts
preliminaryRefund =
  paidAmount - valueOfActuallyProvidedPeriod - documentedActualExpenses;
```

Автоматический расчет не называется окончательным решением.
